NEON Control contempla Minecraft Java Edition y Bedrock Edition. Paper es el primer motor Java previsto y se integra como runtime externo, sin fork ni incorporación de su código al panel.

La documentación describe el diseño previsto para V1.0. Las funciones aún no implementadas se identifican como objetivos y no como capacidades disponibles.
